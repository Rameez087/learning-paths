3.3 Machine learning core you must be fluent in

Reading research assumes a shared vocabulary: bias, variance, generalisation, validation and metrics. Fluency here saves you from the most common mistakes.

TL;DR
You should be able to explain overfitting, the bias variance trade-off, why we hold out validation and test sets, how cross validation works, and which metric fits which problem. Most reproducibility failures come back to one of these basics.

Pick the right measure

A fraud model sees fraud in 0.5% of transactions and reports 99.5% accuracy.
On heavily imbalanced data accuracy is dominated by the majority class.
You tune hyperparameters on the test set and report the best test score.
Selecting on the test set leaks information. Tune on validation data and test once.
Training accuracy is 99% and validation accuracy is 71%.
A large gap between training and validation performance is the classic overfitting signature.

Check your understanding

1. What is the validation set used for?
Validation guides choices. The test set gives the final, untouched estimate.
2. Why is accuracy a poor metric on a 99:1 imbalanced dataset?
Accuracy hides failure on the rare class, which is usually what you care about.
3. A large gap between training and validation scores most likely signals:
The model performs far better on data it has seen than on new data.
