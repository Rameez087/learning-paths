3.4 Data systems foundations

Your edge over most beginners is production data experience. This page names the database concepts research papers assume, so you can connect your daily work to the literature.

TL;DR
Database research asks questions about storage, query processing, transactions, dataflow and data quality. You already use these daily. Learning the vocabulary (indexes, ACID, schemas, lineage, batch versus stream) lets you read data management papers and see where your own experience supplies the questions.

Concepts to be fluent in

Row stores suit transactions, column stores suit analytics. An index trades write cost and space for faster reads. Know what a B-tree and a hash index each do.

ACID: atomicity, consistency, isolation, durability. Isolation levels trade correctness against concurrency. These are the guarantees databases give so applications do not have to.

Batch processing handles bounded data. Streaming handles unbounded data. Systems such as Spark sit in this space, and papers on them often discuss fault tolerance and exactly once semantics.

Constraints, profiling and validation catch bad data. Lineage records how a value was derived, at table, column or row level. The finer the granularity, the more costly it is to capture.

Two free resources
Designing Data-Intensive Applications by Martin Kleppmann explains storage, replication, transactions and dataflow clearly. CMU 15-445 publishes its database systems lectures publicly. Between them you can cover the vocabulary that data management papers assume.

Name the concept

Your Power BI total disagrees with the SAP source because two systems use different customer IDs for the same company.
Deciding that two records refer to the same real world entity is entity resolution, an active research area that LLMs are now applied to.
You want to know which source columns feed a particular dashboard measure.
Tracing derived values back to their source columns is lineage, which you have already built a tool for.

Check your understanding

1. What does the I in ACID, isolation, protect against?
Isolation governs how concurrent transactions see each other's changes.
2. What is entity resolution?
It is a core data integration problem and a common research topic.
3. Why does column level lineage cost more than table level lineage to capture?
Finer granularity requires parsing or instrumenting the transformations, not just the job graph.

Sources: Designing Data-Intensive Applications (Kleppmann); CMU 15-445 Database Systems; OpenLineage
