9.4 Cost optimisation

Cloud bills grow quietly. A few habits and a few discounts keep them in check.

TL;DR
Cost control is a loop: see costs with tags and budgets, remove waste (idle resources, oversized VMs, orphaned disks), right size, then commit for steady usage through reservations or savings plans. Use spot capacity for interruptible work and dev/test schedules to stop non production overnight. Azure Advisor lists recommendations.

Try it: is a reservation worth it?

A reservation discounts a steady resource in return for a one or three year commitment. You pay for every hour whether you use it or not. Enter an example hourly price and discount (use your real figures from the pricing page) and see the break even.

  • Tag every resource with owner, environment and cost centre, and enforce it with policy.
  • Set budgets with alerts at a few thresholds.
  • Review Advisor and Cost analysis monthly.
  • Delete tutorial resource groups when finished.
