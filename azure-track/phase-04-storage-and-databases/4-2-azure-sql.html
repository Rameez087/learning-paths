4.2 Azure SQL

Azure SQL is a family. Pick by how much of SQL Server compatibility and control you need.

TL;DR
Azure SQL Database is a fully managed single database or elastic pool, the usual choice for new apps. SQL Managed Instance is near full SQL Server compatibility for lifting existing workloads. SQL Server on a VM gives complete control and the most to manage. Purchasing models are vCore based or DTU based, and a serverless compute tier can pause when idle.
OptionBest forYou manage
SQL DatabaseNew cloud apps, SaaS, many small databases (elastic pool)Schema and data
Managed InstanceMigrating instance scoped features like SQL Agent, cross database queriesSchema, data, instance settings
SQL Server on a VMUnsupported features, full OS accessEverything from the OS up

Concepts you will meet

  • Serverless: auto scales compute and can auto pause, billed per second of use. Good for intermittent workloads.
  • Elastic pools: share resources across databases with different peak times.
  • High availability and backups: automatic backups with point in time restore, optional zone redundancy and geo replication.
  • Security: Entra authentication, private endpoints, transparent data encryption by default, and auditing.
Check the current limits
Service tiers, sizes and features change. Read the current docs before committing to a design, especially for Hyperscale, serverless pause delays and zone redundancy support.

Which Azure SQL option?

A new multi tenant SaaS app with hundreds of small databases with uneven load.
Pools share compute across databases whose peaks differ.
Moving an on premises instance that uses SQL Agent jobs and linked servers.
Managed Instance supports instance level features.
A dev database used a few hours a day.
Serverless pauses and bills only for use.

Check your understanding

1. Which option has near full SQL Server instance compatibility as a managed service?

2. What is an elastic pool for?
It saves cost when databases do not peak together.
3. When can serverless help most?
It can pause when idle.
