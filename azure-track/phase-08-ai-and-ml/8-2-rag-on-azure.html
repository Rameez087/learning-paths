8.2 RAG on Azure: AI Search or pgvector

Retrieval augmented generation needs a retrieval layer. Azure gives you two good routes, with different trade offs.

TL;DR
RAG retrieves relevant chunks and passes them to a model. On Azure, Azure AI Search is a managed search service with keyword, vector and hybrid search, semantic ranking, filters and built in ingestion helpers. PostgreSQL with pgvector (4.4) keeps vectors beside relational data with SQL filters. Pick based on scale, ranking needs and operations.
Azure AI SearchPostgreSQL + pgvector
Search typesKeyword, vector, hybrid, semantic rerankingVector similarity, plus Postgres full text if you build it
OperationsManaged search service, capacity in unitsA database you may already run
Joins and filtersFilter on fields, limited joinsFull SQL joins and transactions
ScaleBuilt for large indexes and high query loadGood at moderate scale, tune indexes
CostSeparate service chargeShares your database cost
Best fitDocument heavy apps, strong ranking qualitySmall teams, relational data, simple stack
Retrieval quality limits answer quality, so measure it (8.6).

Choices that matter more than the database

  • Chunk size and overlap, and keeping headings with their text.
  • Hybrid search often beats vector alone, because exact terms like IDs and names matter.
  • Metadata filters for tenant, language, date and permissions.
  • Security trimming: never retrieve documents the user is not allowed to see.
  • An evaluation set to measure retrieval and answers (8.6).
Research link
RAG evaluation and defects are a project area in the Research Track, if you want to turn this into a measurable study.

Pick the retrieval layer

500,000 PDFs, need strong ranking, hybrid search and semantic reranking.
Search is purpose built for large document ranking.
A department app with 20,000 chunks and rich relational filters already in Postgres.
Simplicity wins at modest scale.

Check your understanding

1. Why hybrid search?
Combining keyword and vector often improves recall.
2. What is security trimming?
Retrieval must respect permissions.
3. When is pgvector a fit?
It keeps the stack simple.
