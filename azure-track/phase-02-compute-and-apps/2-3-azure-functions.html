2.3 Azure Functions

Small pieces of code that run when something happens: a request, a message, a file, a timer. You pay for what runs and skip the servers.

TL;DR
Azure Functions runs code in response to triggers (HTTP, timer, queue, blob, event hub) with bindings that connect input and output without boilerplate. Hosting plans include Consumption, Flex Consumption, Premium and Dedicated, trading cost, cold start behaviour and networking features.

Triggers and bindings

TriggerRuns whenTypical use
HTTPA request arrivesSmall APIs and webhooks
TimerOn a scheduleNightly jobs, clean up
Queue or Service BusA message arrivesBackground processing
BlobA file is added or changedProcess uploads
Event Hub or Event GridAn event arrivesStreams and reactions to Azure events

A binding declares an input or output, for example write a result to a queue or read a blob, so your code focuses on logic. Hosting plans differ in scale, networking and cold starts, so check current limits and pricing before choosing.

# Python v2 programming model: a timer function writing to a queue
import azure.functions as func

app = func.FunctionApp()

@app.timer_trigger(schedule="0 */5 * * * *", arg_name="timer")
@app.queue_output(arg_name="out", queue_name="jobs", connection="AzureWebJobsStorage")
def every_five_minutes(timer: func.TimerRequest, out: func.Out[str]):
    out.set('{"task": "refresh"}')

Choosing a hosting plan

Scales to zero and bills per execution. Cheapest for sporadic work. Cold starts and limited networking options.

A newer serverless option with faster scaling, virtual network support and more control over instance sizes. Check the current regions and features.

Pre-warmed instances, virtual network integration and longer runtimes. Higher baseline cost.

Run on an App Service plan you already pay for. Predictable cost and full platform features.

Keep functions small and idempotent
Triggers can fire more than once (retries, redelivery). Design functions to be safe to run twice. For long workflows use Durable Functions or an orchestrator rather than one huge function.
