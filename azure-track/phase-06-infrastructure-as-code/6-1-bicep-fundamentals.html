6.1 Bicep fundamentals

Bicep is Azure's own infrastructure language. It compiles to ARM templates and is declarative: you describe the end state.

TL;DR
Bicep is a domain specific language for deploying Azure resources. It compiles to ARM JSON, has clean syntax, type safety and editor support, and supports every new Azure resource and API version from day one. A Bicep file has parameters, variables, resources, modules and outputs. Deployments are idempotent: running again makes Azure match the file.

A first file

param location string = resourceGroup().location
param env string = 'dev'
@allowed(['Standard_LRS', 'Standard_GRS'])
param sku string = 'Standard_LRS'

var name = 'st${env}${uniqueString(resourceGroup().id)}'

resource sa 'Microsoft.Storage/storageAccounts@2023-05-01' = {
  name: name
  location: location
  sku: { name: sku }
  kind: 'StorageV2'
  properties: {
    isHnsEnabled: true
    allowBlobPublicAccess: false
    minimumTlsVersion: 'TLS1_2'
  }
}

output id string = sa.id

Deploy it

1. Create a resource group

az group create -n rg-demo -l westeurope

2. Preview

az deployment group what-if -g rg-demo -f main.bicep shows what would change (6.2).

3. Deploy

az deployment group create -g rg-demo -f main.bicep -p env=dev

4. Change and redeploy

Edit the file and run again. Azure applies the difference.

PiecePurpose
paramInputs, with types, defaults and decorators like @allowed and @secure
varComputed values
resourceAn Azure resource, with a type and API version
moduleReuse another Bicep file
outputValues returned after deployment
existingReference a resource that already exists without managing it
Use @secure for secrets
Mark secret parameters with @secure() so values are not logged in deployment history. Better still, avoid passing secrets and use managed identities.

Bicep concept

Reference an existing Key Vault in another file without redeploying it.
existing looks up a resource without managing it.
Restrict a parameter to two allowed values.
Decorators validate parameters before deployment.

1. What does Bicep compile to?
