10.3 Capstone: a landing zone from code

Bring the whole track together: a small, secure, observable environment created entirely from code.

TL;DR
Build a miniature landing zone and one workload on it. Everything is created by a pipeline from a Git repository, with no manual portal steps and no stored secrets.

The brief

  1. A management group structure with a platform and a landing zone group (or, in a single subscription, separate resource groups that mimic it).
  2. A policy baseline: allowed regions, required tags, deny public storage, diagnostics to a central workspace.
  3. A hub VNet with a firewall or NSG based controls, and one spoke for the workload.
  4. A workload: a container app or web app with a managed identity, reading a secret from Key Vault and data from a storage account or database through private endpoints.
  5. Deployment by GitHub Actions with OIDC, a what-if or plan step on pull requests and an approval for the main branch.
  6. Monitoring: logs to Log Analytics, alerts, and a cost budget.
  7. Optional: a RAG endpoint or a small lakehouse as the workload.
