2.3 Attention mechanism deep dive

The full mechanics behind the intuition from 1.2, now with numbers you can actually move.

TL;DR
For every token, attention computes a query (what am I looking for), and every token (including itself) offers a key (what do I contain) and a value (what information do I carry). The query is compared against every key to produce a relevance score, those scores are turned into a probability distribution via softmax, and each token's value is blended into the output weighted by that distribution. Every token does this simultaneously — that's what "self-attention" means.

The three roles: query, key, value

Every token's embedding gets projected three separate ways, using three learned weight matrices:

  • Query (Q) — "what information am I looking for?" Computed from the token that's currently trying to update its understanding.
  • Key (K) — "what do I have to offer?" Computed from every token, including the one asking the query.
  • Value (V) — "here's my actual content, if you want it." Also computed from every token.

The relevance score between a query and a key is their dot product — a similarity measure, same underlying idea as the cosine similarity from 2.2. Those raw scores get scaled and passed through softmax, which converts arbitrary numbers into a clean probability distribution that sums to 1. That distribution is then used to compute a weighted average of every token's value vector — the result becomes the query token's updated, context-aware representation.

Multi-head attention: several perspectives at once

A real transformer doesn't run this process once per layer — it runs it many times in parallel, called attention heads (commonly 8 to 96+ depending on model size). Each head learns its own Q/K/V projections, so different heads end up specializing: research into trained models has found heads that track grammatical subject-verb agreement, heads that resolve pronouns back to the noun they refer to, and heads that track long-range narrative dependencies like the "murderer was" example from 1.2. Their outputs get concatenated and combined, giving the model several independent "lenses" on the same sentence simultaneously.

Temperature: what happens after attention decides

Attention determines which context matters. Once the model has produced a probability distribution over the next token, temperature determines how the model samples from it. Try the slider below on a toy distribution.

Check your understanding

1. What role does the "key" vector play in attention?
The key is compared against the query via dot product to produce a relevance score — it's the "advertisement" of what that token contains, separate from the value, which is the actual content passed forward.
2. Why do transformers use multiple attention heads instead of just one?
Multi-head attention lets the model attend to the same sentence from several independent "perspectives" simultaneously, with different heads often specializing in different linguistic patterns.
3. What does raising the temperature do to the next-token distribution?
Temperature is applied after attention has already produced the raw distribution — it reshapes how sharply peaked that distribution is during sampling, not what the model attended to in order to produce it.

Sources: Vaswani et al., "Attention Is All You Need" (2017); mechanistic interpretability research on specialized attention head behavior (Elhage et al. 2021; Wang et al. 2023, Indirect Object Identification).
