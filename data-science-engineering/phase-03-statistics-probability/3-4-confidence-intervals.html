3.4 Confidence intervals

"95% confident" doesn't mean what almost everyone assumes it means the first time they hear it.

TL;DR
A confidence interval gives a range of plausible values for an unknown population parameter, built from a single sample. The correct interpretation of "95% confidence": if you repeated the sampling process many times and built a new interval each time, about 95% of those intervals would contain the true population value. It does not mean "there's a 95% chance the true value is in this specific interval" — the true value either is or isn't in any given interval; the 95% describes the reliability of the method across repeated sampling, not a probability about this one result.

The direct link between confidence intervals and hypothesis tests

These two tools always agree, because they're built from the same underlying logic: if a 95% confidence interval for a difference excludes 0, the corresponding hypothesis test at α = 0.05 will reject the null hypothesis of "no difference" — and vice versa. This is exactly why good practice recommends reporting both a p-value and a confidence interval together: the p-value tells you whether an effect is statistically detectable, and the interval tells you the plausible range of how large that effect actually is — information the p-value alone doesn't carry.

Width matters as much as whether it excludes zero

A confidence interval of [0.5, 1.5] and one of [0.01, 40] can both "exclude zero" and thus both count as statistically significant — but they tell very different practical stories. A narrow interval suggests a precisely estimated effect; a wide one suggests genuine uncertainty about the effect's actual size, even if you're confident it's not exactly zero. Interval width shrinks with larger sample sizes, which is the direct, practical reason "collect more data" is often the right answer when an interval is too wide to be useful.

Confidence level is a choice, with a real trade-off

A 99% confidence interval is wider than a 95% one for the same data — demanding more confidence means the interval has to cover a larger range of plausible values to maintain that higher reliability across repeated sampling. There's no universally "correct" confidence level; 95% is a convention, not a law of nature, and some fields default to different levels depending on the cost of being wrong.

Check your understanding

1. What does "95% confidence" actually describe?
This is the precise, correct interpretation — it's a statement about the long-run reliability of the method across repeated sampling, not a probability statement about any single interval you've already computed.
2. If a 95% confidence interval for a difference between two groups excludes 0, what does this imply about the corresponding hypothesis test?
Confidence intervals and hypothesis tests are built from the same statistical logic — an interval excluding the null value and a significant p-value at the matching confidence/significance level are two views of the same result.
3. Why might a wide confidence interval be less practically useful even if it excludes zero?
Statistical significance (excluding zero) and estimation precision (interval width) are separate properties — a very wide interval can technically be "significant" while still leaving you with little idea of the effect's true magnitude.
