8.4 Agent memory systems

An LLM is stateless by design. Every API call starts from a blank slate — memory is what an agent adds on top.

TL;DR
The context window (2.5) is an agent's working memory — what it can access right now. Agent memory systems add something categorically different: persistent storage across sessions, typically split into episodic memory (specific past events — "we tried approach X on Tuesday and it failed"), semantic memory (general facts and preferences — "this user prefers Python over TypeScript"), and procedural memory (learned behaviors — "tool A works better than tool B for this task type"). This mirrors human memory categories directly, and it's not a coincidence — several production frameworks explicitly draw on this cognitive-science structure.

Why the context window alone isn't enough

An agent that only has its context window "forgets" everything the moment a conversation ends, or the moment old messages roll out of even a very large window (2.5's context-length limits apply here just as much as anywhere else). For any agent expected to personalize across sessions, learn from past mistakes, or accumulate domain knowledge over time, information has to be deliberately extracted from the working context and written into persistent storage — this is a genuinely separate system from the LLM itself, not a bigger context window.

The extract → consolidate → store → retrieve pipeline

Production memory systems generally follow a consistent pipeline: raw conversation is noisy, so relevant facts get extracted, related facts get consolidated (resolving contradictions — if a user's stated preference changes, the old fact needs updating, not just appending to), the result is stored (commonly in a vector store for semantic retrieval, or increasingly a knowledge graph for relationship-heavy domains), and relevant memories are retrieved at query time and injected into context — this retrieval step is structurally identical to RAG's retrieval (Phase 6), just retrieving from the agent's own memory rather than a document corpus.

The concrete payoff: measured, not just theoretical

One widely cited production memory framework reports benchmark results of roughly 91% lower p95 latency and about 90% token reduction compared to re-reading the full conversation history on every call. This is the direct financial and performance case for structured memory: instead of resending an ever-growing history on every request (paying the quadratic attention cost from 2.4 on the entire accumulated conversation), a memory system retrieves only the small number of facts actually relevant to the current turn.

Vector vs. graph storage for memory

Vector-based memory storage (5.2) is fast for simple similarity-based retrieval but struggles to represent relationships between facts explicitly. Graph-based memory storage is more expressive — naturally representing "who relates to what, and how" — at the cost of schema design and maintenance overhead. The choice affects concrete downstream capabilities: how well the agent handles multi-hop reasoning, whether contradictions can be resolved structurally rather than just overwritten, and how the indexing strategy scales.

Check your understanding

1. What's the key difference between the context window and an agent memory system?
A memory system is a genuinely separate storage layer that survives beyond the lifetime of any single conversation or context window — it's what lets an agent "remember" something from a session that has long since ended.
2. What is procedural memory, in the agent-memory taxonomy?
Procedural memory is about learned "how to" behavior, distinct from episodic memory (specific past events) and semantic memory (general facts) — the human-memory analogy maps directly onto these three categories.
3. Why is the "consolidate" step in the memory pipeline necessary, not just "store everything"?
Without consolidation, an agent's memory can accumulate stale or contradictory facts over time — resolving updates during ingestion is what keeps retrieved memory accurate rather than just historically complete.
